# dsh-image-mention

> 把刚上传的图片**带序号和文件名** `@` 进对话 —— 让模型分得清你说的是哪一张。
> Mention the images you just attached, by name and by ordinal.

DSH（DeepSeek Harness）Web 端的一个微型插件。

贴了图之后，在输入框里打 `@`，菜单里会多出一组**本轮图片**（缩略图 + 文件名 + 尺寸）：

```
@   →   第 1 张图    Q版.png         1273×1739
        第 2 张图    Q版三视图.jpg    2741×1530
```

选中一张，输入框里出现引用块 `图 Q版.png`；发送之后，模型收到：

```
【本条消息第 2 张图："Q版三视图.jpg"】
```

**点击那个引用块**，可以全屏预览原图（点空白处或按 Esc 关闭）。

## 为什么要做它

平台把图片交给模型时，只会说「这是 `Q版.png`（sha256:…，1273×1739px）」——
**它从不说「这是第几张」**。图片和文字混在一起、或者几张图同名时，模型只能猜。

这个插件把「第几张 + 文件名」这个锚点补上：序号在**引用那一刻**绑定，
和它后来在文字里排第几无关（打乱顺序、剪切粘贴都不会串号）。

## 特点

- **零依赖** —— 只用客户端已提供的 react，装完不用联网
- **纯浏览器侧** —— 宿主半边是空壳，不注入任何平台服务，不会把谁挂在 `pending`
- **不碰平台 id** —— bundle patch 只有一条 `insert`，行 id = 包名，构造上撞不了车
- **能力面最小** —— 不读文件、不联网、不执行命令、不碰凭据
- **优雅降级** —— 拿不到草稿预览信息时照旧能 `@`，只是点引用块不弹预览

## 安装

```bash
# 从 GitHub 直装（不需要 npm 账号）
dsh plugin --profile <你的 profile> add github:<你>/dsh-image-mention
```

也可以**零安装热挂载**（不改任何包，只往 profile 的 `cordis.patch.yml` 追加 3 行），
详见 [INSTALL.md](INSTALL.md)。

## 一条平台硬规则

`@` 必须落在**行首**或**空白之后**。`aa@`、`你好@`、`）@` 都**不会**弹菜单——
平台自带的 `@文件` / `@会话` 走同一条检测路径，一样如此。
所以要引用第二张时，`@` 前面**留一个空格**。
